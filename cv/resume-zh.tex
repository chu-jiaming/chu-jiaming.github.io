\begin{experiences}
  \experience%
    {2026}%
    {\projecttitle{VGGT-Splat：VGGT 能否替代 COLMAP 做 3DGS 重建} \hfill
     \pagelink{https://chu-jiaming.github.io/vggt-splat/}{项目主页}\enspace
     \codelink{https://github.com/chu-jiaming/VGGT-Splat}{代码}}%
    [\begin{itemize}
      \item 问题：手机视频做 3D 高斯（3DGS）重建要先估计位姿。COLMAP 和前馈模型 VGGT 各需要多少帧？少帧时 VGGT 深度先验有用吗？
      \item 做法（独立完成）：6 个场景 $\times$ 4 种帧数（8 / 16 / 32 / 全部）$\times$ 3 种方法，共 72 次实验
      \item 结果一：\keypoint{少帧时 VGGT 更可靠，全部帧时 COLMAP 更好。}COLMAP 在 8 帧时 4/6 个场景失败、16 帧时 3/6 个场景失败，VGGT 未失败；
        全部帧时 COLMAP 在 5 个场景领先 2.1--4.6\,dB，可能因为 VGGT 位姿精度较低
      \item 结果二：\keypoint{深度先验几乎不提升新视角质量。}少帧时误差集中在训练视角没拍到的区域，深度损失约束不到
    \end{itemize}]
  \separator{0.5ex}
  \experience%
    {2026}%
    {\projecttitle{PoseGuard-NeRF：联合相机位姿优化何时帮助 NeRF} \hfill
     \pagelink{https://chu-jiaming.github.io/poseguard-nerf/}{项目主页}\enspace
     \codelink{https://github.com/chu-jiaming/PoseGuard-NeRF}{代码}}%
    [\begin{itemize}
      \item 问题：NeRF 依赖准确位姿。训练时联合优化位姿可以修正误差，但何时有用、何时有害？
      \item 做法（独立完成）：Lego 场景，9 种位姿条件 $\times$ 5 种方法，共 45 组 vanilla NeRF 实验；用 Sim(3) 对齐区分重建变差和坐标偏移
      \item 结果一：\keypoint{位姿有噪声时，联合优化明显有用。}5\% 平移噪声下，PSNR 从固定位姿的 14.1\,dB 升至 22.7\,dB（加 warm-up）
      \item 结果二：\keypoint{位姿准确时，联合优化反而降低 PSNR，主要原因是全局坐标漂移。}不加 warm-up 时由 27.1 降至 17.9\,dB，
        Sim(3) 对齐后恢复 5.5\,dB
    \end{itemize}]
  \separator{0.5ex}
  \experience%
    {2026}%
    {\projecttitle{AFVE-Bench：LLM 改写中的旧框架残留评测} \ifdef{\publicbuild}{（Under Review）}{\privatenote{notezh}}\hfill
     \paperlink{https://chu-jiaming.github.io/papers/afve-bench.pdf}{预印本}}%
    [\begin{itemize}
      \item 问题：用户要求换框架重写时，模型可能写对了新内容，却仍暴露旧框架。现有评测主要看最新要求，容易漏掉
      \item 做法（第一作者）：192 组中英双语四轮对话，覆盖 8 类写作任务；11 个模型配置的 4,204 条回复经双人盲标与仲裁
      \item 结果：\keypoint{满足新要求不等于旧框架不再暴露。}此前按旧框架写过内容的回复中，25.5\% 出现这类错误；已满足新要求的回复里，仍有 19.8\% 暴露旧框架
    \end{itemize}]
\end{experiences}
